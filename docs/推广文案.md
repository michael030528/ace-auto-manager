# 推荐主文案

## 游戏关了，ACE 也该休息了。

退出游戏后，ACE 还在后台？不想每次都手动关托盘、查服务？

试试 **ACE 自动管理**：下载一个 EXE，打开中文窗口，点一下就能开启自动管理。

- 玩游戏时，由游戏正常启动 ACE。
- 退出游戏和相关客户端后，等待 45 秒自动尝试清理。
- 登录电脑后不玩游戏，也可以自动关闭后台 ACE。
- 随时暂停、卸载自动管理，原始 ACE 启动设置保留。
- 根据本机 ACE 组件自动识别游戏，不用逐个手填进程名。

**少一点后台常驻，少一点手动操作。**

开源、单文件、无需 Python。自动发现带有 ACE 组件的游戏，已有无畏契约、英雄联盟及云顶布局适配。请确认监测名单完整，勿与其他未被监测的 ACE 游戏同时使用。

下载：https://github.com/michael030528/ace-auto-manager/releases/latest

非官方工具；不承诺性能提升或所有游戏都无需重启。

# 群聊 / 朋友圈短版

做了个 ACE 自动管理小工具：游戏退出后，等 45 秒自动尝试关掉后台 ACE；下次游戏照常自行启动反作弊。中文窗口，一键设置，也能随时暂停。省去每次手动查进程、关托盘的麻烦。

会根据本机 ACE 组件自动发现游戏，也可手动补充。开源单文件 EXE：
https://github.com/michael030528/ace-auto-manager/releases/latest

注：自动发现不等于已验证每款游戏兼容；无需重启的效果已在本机无畏契约验证，不保证所有环境一致。
