# 游戏关了，ACE 也该休息了。

ACE 自动管理首个图形界面版本：下载 `ACE-Auto-Manager.exe`，双击打开中文窗口，检查游戏名单，点击“一键开启自动管理”。

## 功能

- 单文件 EXE，无需 Python 或 .NET SDK。
- 根据安装记录、Steam / WeGame 库及 ACE 组件文件自动发现游戏，不只识别固定名称；同目录相关进程会阻止误清理，也可手动添加。
- 游戏和相关客户端全部退出后，默认 45 秒自动尝试关闭 ACE。
- 可选登录后无游戏时自动清理；支持暂停、卸载自动任务和查看日志。
- 支持升级此前安装的 ACE Game Auto Close 脚本任务。

**不玩游戏时少一点后台常驻，少一点手动清理。**

## 下载

直接下载下方 `ACE-Auto-Manager.exe`；或下载包含说明和校验文件的 ZIP。

## 使用边界与验证

Windows 10/11 x64。安装前请确认自动识别名单完整，勿与其他未监测的 ACE 游戏同时使用。自动发现属于文件结构判断，不是兼容性认证。游戏自行启动 ACE，程序不绕过反作弊；无法正常停止的组件会在状态中报告。

本机无畏契约已验证关闭后能直接重新启动 ACE，但其他环境可能需要暂停自动管理后重启。本工具不保证帧率提升或所有游戏兼容。

已通过 42 项状态机、模拟关闭、配置、自动发现与目录保护检查，以及 EXE 自检、真实窗口/状态读取检查。管理员安装流程在不同电脑上仍需验证。EXE 暂未代码签名，可用 SHA256SUMS.txt 校验。
