# v1.1.0

新增立即清理、残留组件详情和失败自动重试，方便游戏结束后确认 ACE 是否已经关闭。

- 立即清理请求交由后台串行执行；发现游戏或相关客户端时拒绝关闭，停止各组件前仍会复查。
- 实时列出残留驱动、服务、进程及 PID。
- 清理失败最多额外重试 3 次，间隔至少 60 秒；检测到游戏取消重试，退出后重新计时。
- 卸载确认后移除任务、关闭窗口并删除当前运行的 EXE；保留其他副本、后台安装文件、配置和日志。文件被替换时停止删除，删除失败会提示。
- 识别已有安装并显示“一键开启自动管理”，读取已有设置后覆盖后台，不替换其他下载的 EXE。

**旧用户：打开新版后点击“一键开启自动管理”，才能启用新版后台功能。**

59 项检查及 EXE 构建自检通过。服务关闭使用隔离模拟测试，EXE 删除使用临时文件测试；已检查实际界面，未完成所有机器上的管理员升级与卸载全流程测试。
